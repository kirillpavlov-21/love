# Свой сервер для «Куда идём?» — без Яндекса и Сбера

Одна команда ставит на чистый VPS всё сразу: API (голоса, ответы, отзывы, короткие ссылки), HTTPS и — по желанию — зеркало сайта на российском IP (на случай, если GitHub в России открывается плохо). Каждый день в 04:10 база копируется, каждые 15 минут сервер подтягивает свежий код из `main`.

## Какой сервер взять
- Любой российский VPS **вне Москвы и области**, лучше Новосибирск или Екатеринбург: 1 vCPU, 1 ГБ памяти, Ubuntu 24.04. Например, RUVDS «Старт Хит SSD» в Новосибирске (~349 ₽/мес) или Timeweb Cloud в Новосибирске.
- Данные лежат в России — это требование 152-ФЗ к хранению персональных данных.
- Для надёжности позже: копии базы к другому провайдеру в другом регионе (`RCLONE_REMOTE` в `backup.sh`) и холодный запасной сервер — та же команда на втором VPS.

## Установка (10 минут)
1. Купи VPS, выбери Ubuntu 24.04, запомни IP и пароль root (или добавь SSH-ключ).
2. Домен для API:
   - **есть домен** — создай A-запись `api.<домен>` → IP сервера (и `<домен>` → IP, если нужно зеркало сайта);
   - **для теста без домена** — используй `api.<IP-через-дефисы>.sslip.io`, например для 203.0.113.7: `api.203-0-113-7.sslip.io`. Ничего настраивать не нужно.
3. Зайди на сервер (`ssh root@<IP>`) и выполни:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/kirillpavlov-21/love/main/deploy/vps/setup.sh -o setup.sh && bash setup.sh api.203-0-113-7.sslip.io
   ```
   С зеркалом сайта: `bash setup.sh api.kuda-idem.ru kuda-idem.ru`.
4. Сохрани пароль модерации, который скрипт покажет в конце.
5. В `config.js` сайта: `api: { url: 'https://api.203-0-113-7.sslip.io' }` → закоммить в `main`. Готово: голоса видны всем, работают отзывы и «Мои приглашения».

## Полезное
- Проверка: `curl https://<домен API>/?ratings=1` → `{"ok":true,…}`.
- Модерация отзывов: `https://<домен API>/admin`.
- Журналы: `cd /opt/kuda/deploy/vps && docker compose logs -f api`.
- Копии базы: `/opt/kuda-backups/` (14 дней). Вручную: `/opt/kuda/deploy/vps/backup.sh`.
- Восстановить из копии: `docker compose cp /opt/kuda-backups/kuda-ГГГГ-ММ-ДД.db api:/data/kuda.db && docker compose restart api`.
- Переезд на другой сервер: та же команда на новом VPS → восстановить копию → поменять A-запись (или `api.url`).
- Секреты (`ADMIN_TOKEN`, `HASH_SALT`) лежат в `/opt/kuda/deploy/vps/.env`. `HASH_SALT` не меняй — иначе сбросятся лимиты и связь отзывов с устройствами.
