# Вход через Яндекс ID: как включить

Кнопка «Войти» уже есть в шапке главной. Пока в `config.js` не указан `auth.yandexClientId`, она показывает «Вход через Яндекс появится совсем скоро». Чтобы включить вход:

1. Открой https://oauth.yandex.ru/client/new (войди своим Яндекс ID).
2. Название сервиса — как сайт (например, «Куда идём?»), иконка — `assets/icon-512.png`.
3. Платформа — **Веб-сервисы**. В **Redirect URI** впиши адрес главной **точно**, вместе с `start.html`:
   `https://kirillpavlov-21.github.io/love/start.html`
   (если сайт переедет на свой домен — добавь и новый адрес, например `https://pozovi.ru/start.html`).
4. Доступы: **Доступ к логину, имени и фамилии, полу** и **Доступ к портрету пользователя**. Почту и телефон не запрашивай — они не нужны.
5. Сохрани. На странице приложения скопируй **ClientID** и вставь в `config.js`:
   ```js
   auth: { yandexClientId: 'тут_ClientID' },
   ```
6. Подними `?v=` в `start.html`, `create.html`, `index.html`, задеплой и проверь: «Войти» → Яндекс → возврат на главную с твоим именем в шапке.

## Как это устроено

- Поток OAuth 2.0 «токен в адресе» (`response_type=token`) — без своего сервера (`assets/auth.js`).
- После возврата сайт один раз запрашивает `login.yandex.ru/info` (имя и аватар), сохраняет их в браузере и забывает токен.
- Защита от подмены — параметр `state`, который сверяется после возврата.
- Что даёт вход сейчас: имя подставляется в конструкторе, аватар в шапке. Когда появится сервер, по тому же входу можно будет синхронизировать «Сохранённые», историю приглашений и рекомендации между устройствами.
