# Посредник для Telegram (Google Apps Script)

Сайт публичный, поэтому токен бота на нём хранить нельзя. Ответы уходят сюда, а скрипт пересылает их тебе в Telegram. Токен и chat_id живут только в скрипте, в твоём Google-аккаунте.

## Настроить с нуля (в браузере)

1. Открой https://script.google.com → **Новый проект**.
2. Вставь в редактор содержимое `Code.gs` и впиши в начале свои `TG_TOKEN` (от @BotFather) и `TG_CHAT` (твой chat_id).
3. **Настройки проекта (⚙️)** → включи «Показывать файл манифеста appsscript.json» → замени его содержимым `appsscript.json` отсюда.
4. Выбери функцию `authorize` → **▶ Выполнить** → разреши доступ. Появится «Google не проверил это приложение»: жми «Дополнительно» → «Перейти в проект». Это твой собственный скрипт. В Telegram придёт тестовое сообщение.
5. **Начать развёртывание → Новое развёртывание** → тип «Веб-приложение», «Запуск от имени: я», «Доступ: все» → **Развернуть**.
6. Скопируй адрес вида `https://script.google.com/macros/s/…/exec` и вставь его в `config.js` → `telegram.relayUrl`.

## Сменить токен (если бот скомпрометирован)

@BotFather → `/revoke` → новый токен → впиши его в `TG_TOKEN` в скрипте → **Развернуть → Управление развёртываниями → ✏️ → Версия: новая → Развернуть**. Адрес при этом не меняется, сайт трогать не нужно.

## Защита

- Через адрес посредника можно только отправить тебе сообщение. Прочитать что-то или узнать токен нельзя.
- Не больше 40 сообщений за 10 минут, чтобы посредник не заспамили.
