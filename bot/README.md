# Telegram-бот «Куда идём?»

Бот повторяет главную сайта прямо в чате: подбирает планы на вечер по обычной фразе, показывает афишу, «удивляет» и собирает голосование «куда идём» и «когда всем удобно». Подбор тот же, что на сайте: бот берёт `assets/intent.js` (разбор фразы) и `assets/pick.js` (оценка планов: время дня, часы работы мест, бюджет, станция, настроение) вместе с каталогом из папки репозитория. Её каждый вечер обновляет ежедневная задача, а на сервере — `git pull`; раз в час бот перечитывает каталог сам. Файлы сайта бот выполняет в отдельной песочнице V8 без доступа к процессу и токену: их дописывает робот каталога, поэтому бот считает их чужим кодом.

## Что умеет

| Где | Что |
|---|---|
| Личка, любая фраза | «свидание недорого, если дождь», «нас пятеро в субботу, баня», «бар с видом у Чистых прудов» → «Понял так: …», три плана с причинами («открыто до 23:00 · 8 мин пешком от м. Чистые пруды»), места и события. Кнопки: **Голосование в чат**, **Ещё варианты**, **Позвать игрой** (конструктор сайта уже с этими планами), **Открыть на сайте** |
| `/podobrat` | квиз кнопками: с кем → бюджет → когда (сегодня, завтра, выходные, поздно) |
| `/udivi` | «Удиви меня» — хороший план на сейчас, с фото (автор и лицензия в подписи) |
| `/afisha` | афиша города: сегодня, завтра, на выходных |
| `/gorod` | Москва или Петербург (бот запоминает; «в Питере …» в запросе тоже переключает) |
| **Любой чат**, `@бот что хотим` | голосование кнопками: карточка с вариантами, каждый жмёт свои, карточка сама показывает, кто за что и кто лидирует. Бота в чат добавлять не нужно |
| `@бот когда` | голосование по дням: ближайшие 7 дней |
| Группа с ботом | `/opros баня или бар в пятницу` — нативный опрос Telegram (открытый, можно несколько ответов) и ссылки на варианты; `/kogda` — опрос по дням. В группе бот отвечает только на команды, на `@бот …` и на ответы на свои сообщения |
| Ссылка с сайта | `t.me/<бот>?start=poll_<номер>_<номер>…` — бот покажет эти планы и кнопку «Голосование в чат» |

## Запуск за 5 минут (на ноутбуке)

1. **Бот.** В Telegram открой [@BotFather](https://t.me/BotFather):
   - `/newbot` → имя («Куда идём?») и ник, оканчивающийся на `bot` → BotFather пришлёт **токен**.
   - `/setinline` → выбери бота → подсказка в поле ввода, например `свидание, баня, бар с видом…`. Без этого голосование в чужих чатах не заработает.
   - `/setjoingroups` → Enable — чтобы бота можно было добавить в группу ради нативных опросов.
   - По желанию: `/setdescription`, `/setuserpic`, а **Bot Settings → Menu Button** → адрес сайта — кнопка «Открыть» внизу чата откроет сайт прямо в Telegram.
2. **Запуск** (нужен Node 22):
   ```bash
   TG_TOKEN='123456:AA…' node bot/poll.mjs
   ```
   Бот сам поставит список команд и напишет в консоль ссылку на себя. Пока окно открыто — бот работает. Ctrl+C — остановить.
3. **Сайт.** В `config.js → telegram.app` впиши ник бота без `@` — под подборкой «Куда пойти сегодня» появится кнопка «Голосование в Telegram». Не путай с `telegram.bot`: там бот-посредник для уведомлений (relay/), он сам забирает свои обновления, и один токен на двоих сломает обоих.

Переменные окружения: `TG_TOKEN` (обязательно), `SITE_URL` (адрес сайта для ссылок, по умолчанию GitHub Pages), `BOT_DATA=site` (брать каталог прямо с сайта, без `git pull`), `BOT_STORE` (файл хранилища, по умолчанию `~/.kuda/bot-store.json`, права только у владельца), `TG_API` (свой сервер Bot API, если есть).

## Чтобы бот работал всегда

Ноутбук засыпает — бот тоже. Для круглосуточной работы нужен сервер **за рубежом**: с 2026 года с российских серверов `api.telegram.org` часто недоступен, поэтому Yandex Cloud и российские VPS для этого бота не подходят.

- **Свой VPS** (любой зарубежный, от ~3 $/мес) — клон репозитория, `node bot/poll.mjs` под systemd или pm2 и `git pull` по расписанию раз в день; домен не нужен.
- **Хостинг с https** (Render, Fly.io, Railway) — вебхук:
  ```bash
  TG_TOKEN='…' PUBLIC_URL='https://bot.example.com' TG_SECRET='длинная-случайная-строка' node bot/webhook.mjs
  ```
  Сервер слушает `PORT` (8080), путь `/tg`, сам ставит вебхук и проверяет секрет в заголовке `X-Telegram-Bot-Api-Secret-Token`. Хранилищу (`BOT_STORE`) нужен постоянный диск, иначе голосования пропадут при перезапуске.

## Telegram в России

С февраля 2026 года Telegram в России замедляют, с весны — массово блокируют; часть людей заходит через VPN. Поэтому главным остаётся сайт: бот — удобный вход для тех, кто в Telegram, а все его ответы ведут на сайт, который открывается в любом мессенджере и браузере. Следующий шаг — мини-приложение и бот в MAX (там нет опросов и inline-режима, голосование — кнопками, как у нас; регистрация ботов — для ИП, юрлиц и самозанятых).

## Что бот хранит

Файл `BOT_STORE` (вне репозитория):

- `u:<id пользователя>` — выбранный город и «с кем» (год);
- `q:<код>` — текст запроса и показанные планы — для кнопок «Ещё» и «Опрос» (2 дня);
- `v:<код>` — голосование: варианты и голоса — id и имя из Telegram, чтобы показать «Аня, Петя» (30 дней после последнего голоса).

Переписку бот не хранит. Это персональные данные (id и имя в Telegram) — они описаны в [privacy.html](../privacy.html#bot).

## Проверка

```bash
cd bot && npm test
```

Тесты идут на настоящем каталоге из репозитория с поддельным Telegram, без сети: разбор фраз, подбор (только открытые места, разные планы, «под крышей», станция), сценарии бота — фраза в личке, голосование кнопками (голос, снятие голоса, лидер, ничья), опрос в группе, квиз, ссылка с сайта и смена города.
