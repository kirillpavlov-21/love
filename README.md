# 📍 Куда идём?

Готовые планы на вечер в Москве и приглашения-игры для телефона. Три режима:

| Режим | Что внутри |
|---|---|
| 💕 **Свидание** | игра-приглашение для неё: сердечки → письмо с убегающей «Нет» → шарики с местами → календарь → время → еда → билет на свидание |
| 🍻 **Пацаны** | групповое приглашение с голосованием: мини-игра → «Погнали?» → свайпы «за/против» по планам → отметить удобные дни → итоги |
| 💅 **Подружки** | то же для девичника, в своём оформлении |

На главной — 110 готовых планов «занятие + еда/бар рядом» (с фильтрами «днём», «вечером», «недорого», «активно», «культура», «с видом») и каталог «Все места» на 234 места с поиском и категориями. У любого места есть кнопка «Позвать сюда»: в приглашение оно попадает как план из одной точки (`p-<id места>`). Работу каждого места проверяли в октябре 2026 года (поле `chk`): время пешком между точками и маршрут через все точки в Яндекс Картах. Ниже — блок 18+ за подтверждением возраста: 22 места (стриптиз-клубы, мужской стриптиз, бурлеск-шоу, поле `a18`). Набор вкладок зависит от режима (мужской стриптиз — только в «Подружках», на свидании — только бурлеск), приглашения в эти места не создаются.

**Сайт:** https://kirillpavlov-21.github.io/love/ · **Конструктор:** https://kirillpavlov-21.github.io/love/create.html

## Файлы

```
start.html        — главная «Куда идём?» (сюда ведёт адрес сайта)
index.html        — игра; открывается по ссылке-приглашению
create.html       — конструктор
config.js         — настройки: адрес посредника для Telegram + приглашение по умолчанию
assets/places.js  — места и готовые планы (правь здесь)
assets/app.js     — логика игры
assets/shared.js  — общий код: режимы, котик, ссылки, даты, Яндекс Карты
assets/hub.*      — главная
assets/create.*   — конструктор
relay/            — шаблон посредника Google Apps Script (без секретов)
```

## Как сделать приглашение

1. Открой главную, выбери режим и план → **«Позвать…»**, или сразу открой конструктор.
2. В конструкторе: режим, имена, варианты (готовые планы или свои), даты. Справа живое превью.
3. **«Скопировать»** → отправь ей (свидание) или в общий чат (пацаны/подружки).

Всё приглашение зашито в саму ссылку, поэтому сайт под каждого человека перезаливать не нужно. В ссылку попадает только то, что отличается от `config.js`, поэтому она короткая.

## Голосование (без сервера)

Голоса хранятся прямо в ссылке:

1. Каждый открывает ссылку, проходит игру и отмечает «за/против» и удобные дни.
2. В конце нажимает **«Отправить ссылку в чат»**: в новой ссылке уже лежат все голоса, которые были до него, плюс его собственный.
3. Последняя ссылка в чате всегда показывает полные итоги. Если двое проголосовали одновременно и ссылки разошлись, их можно объединить: кнопка «Объединить» на экране итогов.
4. При ничьей можно крутить колесо 🎡.
5. Кнопка **«Отправить итог в чат»** собирает победивший план, маршрут и день в одно сообщение. Там же — «Добавить в календарь».

На сервер ничего не сохраняется: ни имена, ни голоса.

## Ответы

- **Свидание.** В финале она жмёт «Отправить ответ» и присылает тебе ссылку-билет с выбранным местом, днём и временем. Если в конструкторе указан **твой ник в Telegram**, кнопка сразу открывает ваш чат с готовым текстом ответа — останется нажать «Отправить».
- **Календарь.** На билете и в итогах голосования есть «В календарь» (файл .ics для iPhone и Android) и «Google Календарь».
- **Твои приглашения + Telegram.** Если в конструкторе введён **ключ владельца**, ответы на твои приглашения приходят тебе в бота через посредника (Google Apps Script). Ответы на приглашения, которые создали другие люди, никуда не отправляются.

```
телефон → посредник (Google Apps Script, твой аккаунт) → Telegram-бот → ты
```

Токена бота и chat_id нет ни на сайте, ни на GitHub. Как настроить посредника: [relay/README.md](relay/README.md).

## Как добавить место или план

В `assets/places.js`:

1. Добавь место в `places`: название, адрес, координаты, метро, цена 1–3, короткое описание. Координаты можно взять в Яндекс Картах: правый клик по точке.
2. Добавь план в `scenarios`: `mode` (`date` / `guys` / `girls`), заголовок, `stops` (id мест по порядку), «почему стоит пойти».
3. В `index.html`, `start.html` и `create.html` подними метку версии `?v=…`, чтобы телефоны не брали старый кэш.

## Проверить у себя

```bash
cd ~/date-invite && python3 -m http.server 8765
```

Открой http://localhost:8765/. Кнопка «Превью без отправки» добавляет `&p=1`: ничего не отправляется и не сохраняется. `&s=3` открывает сразу 3-й уровень. `&r=1` в ссылке с голосами открывает сразу итоги.

## Мелочи

- Нужен iPhone с iOS 16.4+ или любой свежий Android.
- Звук на iPhone играет даже в беззвучном режиме: сайт объявляет себя «медиа». Из-за этого музыка на фоне встанет на паузу при первом касании.
- Описания мест взяты из открытых источников на октябрь 2026. Перед походом стоит проверить часы работы в Яндекс Картах.
